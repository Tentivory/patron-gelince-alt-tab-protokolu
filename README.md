## Neden var?

Çünkü:

1. Ekranda açık duran şey her zaman "yıllık bütçe gerçekleşmesi" değildir.
2. Mayın tarlası bir meslek değildir ama bazen meslektir.
3. Kapı kolu döndüğünde milisaniye değerindedir.
4. Devlet farkındadır. En azından bu repo farkındadır.

## Kurulum

Python 3 yeter. Bağımlılık yok. Patron da yoksa bile çalışır.

```bash
python3 protokol.py
```

Çıktı örneği (her çalıştırmada değişir):

- Tehlike seviyesi ölçülür (1-5)
- Önceki gerçek pencere ifşa edilir
- Resmi Alt+Tab uygulanır
- Ekran masumiyet belgesi basılır
- Damga, imza, tarih düşülür
